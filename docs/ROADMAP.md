# Mati roadmap

M1 neural fundamentals: understand weights, loss, gradients and backpropagation.
M2 tiny language model: next-token prediction.
M3 tiny Transformer: causal self-attention.
M4 own tokenizer and learned weights.
M5 curated Mati/Atmini training data.
M6 external memory, separate from neural weights.
M7 explicit reasoning examples and evaluation.
M8 AtminiBridge for Android integration.
M9 CUDA/GPU-ready training without changing the model API.
M10 versioned checkpoints, export, evaluation and production integration.

Keep five things separate: model weights, training knowledge, memory, runtime state, and Atmini application/action layer.
