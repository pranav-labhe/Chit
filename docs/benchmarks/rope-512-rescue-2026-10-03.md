# RoPE 512-Token Rescue Evaluation

**Decision:** Keep as an unpromoted experiment. Linear decay, a lower peak learning rate, and a longer warmup substantially improved held-out next-token metrics. Generated Golden Set responses remain repetitive and have no independent human ratings, so this checkpoint does not pass the behavioral gate.

## Reproduction details

| Item | Value |
|---|---|
| Config | `configs/chit_rope_512_rescue.json` |
| Checkpoint | `checkpoints/candidates/rope-512-rescue/latest.pt` (local ignored artifact) |

| Training | 2,000 steps, seed 314159, CPU, byte tokenizer, base training corpus |

## Results

| Metric | Original 500-step candidate | Rescue candidate |
|---|---:|---:|
| Held-out NLL (nats/token) | 2.2721 | **1.7709** |
| Perplexity | 9.6996 | **5.8759** |
| Bits per byte | 3.2776 | **2.5545** |
| Next-token accuracy | 35.09% | **49.65%** |
| Golden prompts scorable | 50 / 50 | 50 / 50 |
| Behavioral gate | Closed | **Closed** |

Generated responses still fall into repetitive common-token sequences (for example, `That is the can the the...`). A lower NLL is not evidence of acceptable behavior. Do not promote this model. The full response artifact is `checkpoints/evaluations/rope-512-rescue-responses.json` and is not tracked.

## Follow-up

Investigate generation and training-data alignment, including response boundary / end-of-turn supervision, repetition measurements under the production decoding settings, and RoPE numerical/position tests. Have independent reviewers score a candidate only after outputs are sufficiently well-formed to review. Preserve both failed candidates as baselines.
