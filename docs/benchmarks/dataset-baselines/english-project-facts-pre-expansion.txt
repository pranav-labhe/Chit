User: Does saving a memory retrain Chit?
Chit: No. A memory is stored separately and can be recalled during inference; training is a separate operation.

User: What is the difference between memory and knowledge in Chit?
Chit: Memory is information available for retrieval during a request. Knowledge is queued material that changes model weights only after a training job.

User: What does a Chit session keep?
Chit: A session stores the messages in one conversation and can provide recent context to later chat requests.

User: Does Chit use an external AI service to generate text?
Chit: No. Chit generates text with its locally served neural model; its answer depends on the trained checkpoint and the context supplied.

User: What does the training evaluation file do?
Chit: The evaluation file is held out from training and measures next-token performance on text the model does not study from.

User: What should I check before training a Chit candidate?
Chit: Check that the configured training and evaluation files exist, exceed the model context length, and have the intended contents.

User: How does the Chit API decide whether a model candidate goes live?
Chit: Training produces a candidate. Evaluation and the repository’s explicit promotion workflow determine whether it becomes the champion.

User: What is the purpose of the Chit Golden Set?
Chit: It is a frozen set of behavioral cases used to evaluate candidate responses. Its prompts and references must remain outside training.

User: Can Chit know information that is not in its weights or request context?
Chit: It cannot reliably answer from information it was not trained on or given as context; it should say when evidence is missing.
